# aura.kraftss — Handcrafted Woolen Rangoli Mats & Artisan Decor

Bespoke handcrafted woolen rangoli mats, 3D peacock rugs, floral wedding aisle runners, and chowki decor by **aura.kraftss**.

## ⚜ Features

- **AI 3D Rangoli Studio**: Interactive customizer to preview woolen rangoli mats with generative previews, motifs, palettes, and direct enquiry consultation.
- **Master Atelier Gallery**: High-resolution gallery of wedding aisle runners, rangoli mats, botanical resin keepsakes, and bridal mehandi designs.
- **Custom Order Consultation**: Comprehensive bespoke commission form and direct WhatsApp concierge integration.
- **Artisan Showcase**: Story, verified craftsmanship, customer reviews carousel, and care instructions.

## 🛠 Tech Stack

- **Framework**: Next.js (App Router)
- **Styling**: Tailwind CSS & Luxury Vanilla CSS Design System
- **Icons**: Lucide React
- **Typography**: Playfair Display & Inter

## 🚀 Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.
